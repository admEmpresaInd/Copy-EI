18 · Animacoes

Animacoes do sistema

Quatro keyframes globais usados na pagina. Todos respeitam prefers-reduced-motion e duram menos de 1ms quando o usuario pediu.

fade-up
.7s · cubic-bezier(0.4,0,0.2,1) 
/* keyframe */
@keyframes fade-up {
  from { opacity:0; transform:translateY(32px); }
  to   { opacity:1; transform:none; }
}

/* uso */
.anim     { opacity:0; }
.anim.in  { animation: fade-up .7s var(--ease) forwards; }
glow-pulse
2s · infinite 
/* keyframe */
@keyframes glow-pulse {
  0%, 100% { opacity: .4; }
  50%      { opacity: .8; }
}

/* uso (badge dot) */
.badge-dot {
  animation: glow-pulse 2s infinite;
}
5 sistemas
/* keyframe */
@keyframes gradient-x {
  0%, 100% { background-position: 0% 50%; }
  50%      { background-position: 100% 50%; }
}

/* uso (texto neon animado) */
.hero h1 em {
  background: linear-gradient(135deg,

blink

19 · Delays

Stagger de animacoes

Classes .d1 ate .d6 aplicam delay incremental de 0.1s. Use combinada com .anim e o IntersectionObserver para revelar items em cascata.

.d1
100ms
.d2
200ms
.d3
300ms
.d4
400ms
.d5
500ms
.d6
600ms
/* CSS */
.anim   { opacity: 0; }
.anim.in { animation: fade-up .7s var(--ease) forwards; }

.d1 { animation-delay: .1s }
.d2 { animation-delay: .2s }
.d3 { animation-delay: .3s }
.d4 { animation-delay: .4s }
.d5 { animation-delay: .5s }
.d6 { animation-delay: .6s }

/* JS — IntersectionObserver */
const io = new IntersectionObserver(entries => {
  entries.forEach(e => {
    if (e.isIntersecting) {
      e.target.classList.add('in');
      io.unobserve(e.target);
    }
  });
}, { threshold: 0.1 });

document.querySelectorAll('.anim').forEach(el => io.observe(el));
